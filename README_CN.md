## 功能 :

1. 滚动歌词

2. 逐字歌词

3. 歌词文件运行时解析 [支持列表](https://github.com/typedreammoon/libdlp)

4. 音乐渐进渐出

5. 音乐歌单

6. 音乐封面 KMeans 算法主题色计算

7. 音频可视化

8. 播放器拓展

9. 点击歌词播放

10. 歌词文件导入

11. 歌曲导入

12. [歌曲Tag识别](https://github.com/taglib/taglib)

13. 歌词编辑器

14. 歌曲编辑器

15. 模块化

16. 音频拓展

17. [FLAC 解析](https://github.com/xiph/flac)

18. NCM 解析 (禁止商业用途 仅供学习使用)

19. Taskbar Thumbnail Toolbar

20. Windows SMTC支持

## 路线图 :

1. BPM识别

2. 网络播放

3. 音频渐入渐出

4. 智能识别切歌时间

5. QMC, MFLAC, MGG 解析 (禁止商业用途 仅供学习使用)

6. KGM 解析 (禁止商业用途 仅供学习使用)

7. KWM 解析 (禁止商业用途 仅供学习使用)

8. XM 解析 (禁止商业用途 仅供学习使用)

9. 内置歌词搜索 导入

## 模块

| 模块名称                    | 模块描述         |
|-------------------------|--------------|
| DreamMusicPlayer        | 音乐播放器核心实现    |
| DreamMusicPlayerEditor  | 音乐播放器编辑器实现   |
| DreamMusicPlayerLyric   | 歌词文件解析实现     |
| DreamMusicPlayerNetwork | 音乐网络实现       |
| DreamMusicPlayerUMG     | 音乐播放器 UMG 实现 |
